## Tech Stack
A *Stack Tecnológica* é o conjunto de tecnologias que utilizamos para construir a aplicação.

### **Backend**
- **.NET 8.0**: Uma plataforma de desenvolvimento gratuita, multiplataforma e de código aberto para construir diferentes tipos de aplicações.  
  - Git: [https://github.com/dotnet/core](https://github.com/dotnet/core)
- **C#**: Uma linguagem moderna e orientada a objetos desenvolvida pela Microsoft.  
  - Git: [https://github.com/dotnet/csharplang](https://github.com/dotnet/csharplang)
- **Scrutor**: Uma biblioteca para .NET que adiciona funcionalidades de *assembly scanning* e registro automático de dependências no contêiner de injeção de dependência.  
  - Git: [https://github.com/khellang/Scrutor](https://github.com/khellang/Scrutor)
- **MinIO**: Um serviço de armazenamento de objetos compatível com o protocolo S3 da AWS, usado para armazenar e recuperar arquivos de maneira escalável e segura.  
  - Git: [https://github.com/minio/minio](https://github.com/minio/minio)

---

### **Testes**
- **xUnit**: Uma ferramenta gratuita e de código aberto voltada para testes unitários na plataforma .NET.  
  - Git: [https://github.com/xunit/xunit](https://github.com/xunit/xunit)
- **NSubstitute**: Um framework de *mocking* simples e intuitivo para testes unitários em .NET.  
  - Git: [https://github.com/nsubstitute/NSubstitute](https://github.com/nsubstitute/NSubstitute)
- **Bogus**: Uma biblioteca usada para gerar dados falsos (como nomes, e-mails e endereços) para fins de teste e desenvolvimento.  
  - Git: [https://github.com/bchavez/Bogus](https://github.com/bchavez/Bogus)
